# AquariumStudio 仕様書（メイン）

プレイヤーが水族館（フロア・部屋）を広げながら水槽や館内の構造物を置き、各水槽の中にライブロック・流木・水草・サンゴをレイアウトし、採取した生き物を育てる 3D シミュレーション。
通貨と課金は `docs/monetization.md`、iPhone 版は `docs/iphone-release.md` が正。ここには全体像と、機能ごとの決まりを書く。

## 1. 構成
- フロント・3D：Three.js、Vite、JavaScript（ES Modules）。本番は GitHub Pages（main へのマージで公開）。
- サーバー：Supabase（ログイン・セーブ・ランキング・同盟・財布・共有）。SQL は `supabase/`。
- iPhone アプリ：Capacitor（`npm run app:build`）。App内課金は RevenueCat。
- 共有 URL：Cloudflare Worker（`worker/`、`npm run share:deploy`）。
- 管理者ツール：`admin/`（生物設定を Supabase の `game_config` に保存）。

| フォルダ | 役割 |

| `tanks/` | 水槽と館内オブジェの定義・組み立て・追加削除・設定パネル・水槽の壁でのクリップ |
| `interior/`・`interaction/` | 水槽内モードのカメラ、館内と水槽内のマウス操作・元に戻す |
| `flora/` | 水草・海藻・サンゴ（ハード・ソフト）の組み立てと材質 |
| `water/` | 水面と水紋 |
| `expedition/` | 生き物（データ・体のモデル・泳ぎと行動）、採取（漁法・釣りの場面）、成長・飼育 |
| `breeding/`・`gacha/`・`decor/`・`reserve/` | 繁殖、卵ガチャと限定種、内装ガチャ、環境保護区 |
| `management/`・`game/` | 経済・ステージ・工事時間・財布・アイテム・運営、日課・月間・メール・目標 |
| `visitors/`・`map/` | 来館者、世界地図 |
| `online/`・`share/`・`io/` | Supabase との通信・自動セーブ・購入、水槽の共有と閲覧ページ、レイアウトの保存読込 |
| `ui/` | 画面（HUD・カタログ・各種の一覧と設定・スプラッシュ・チュートリアル・通貨の表示） |

## 3. 機能ごとの決まり

### 起動（スプラッシュ）
- ボクセル調のクジラが泳ぐ画面を出し、その裏で全オブジェのプレビュー画像を撮ってキャッシュし、済んだらフェードアウトする。
- プレビューは背景だけの画像にならないよう、BoundingBox の中心がカメラに収まるように合わせる。

### 館内モード
- 階の移動と、資金によるステージの拡大（床面積が広がる）。増築・昇格・別館・生け簀は工事（`src/building/builder.js`、同時に1件）を通し、加速アイテムで縮められる。
- 置ける物：水槽（30cm キューブ〜180cm、トンネル、円形、海生哺乳類用）と館内オブジェ（水槽台・仕切り壁・入口など）。
- ガラスはどの角度でも破綻しないよう `THREE.DoubleSide` と `depthWrite: false`。
- クリックで選択、ドラッグで移動、レイアウトは JSON で保存・読込。

### 水槽内モード
- 水槽の鉛筆アイコンで中に入り、水槽の全体が収まる距離でカメラを固定する。
- 水槽内の物は水槽のローカルの子として持ち、水槽を動かしても離れない。
- 壁の外へはみ出した部分は、水槽の形（円形は半径、四角は箱）に沿って自動で切り取る。上方向は制限しない。
- ライブロックは置くたびに形（丸・平たい・縦長・ふたこぶ・張り出し・角ばった）をくじで決め、設定パネルで選び直せる。岩肌をなぞる変形（スカルプト）は、保存データが大きくなるため廃止した。

### 生き物
- 種のデータは `src/expedition/creatureData.js`、追加予定種は `speciesRoster.js`。モデルが出来た種だけ本番に出る（`speciesRelease.js`）。
- モデルは参考画像が届いた種だけ作る。総称（属・科レベル）の種は作らない。
- 新しい採取地は、捕れる種が3種そろうまで地図に出さない。

### 通貨・課金・繁殖・ガチャ・保護区
- コインとダイヤ（無償と有償を分けて記録し、無償から使う）。両替は 100ダイヤ → 50,000コインの一方向。
- 繁殖はオスとメス、産卵→ふ化→保育の3段階と期限つきの世話。「3時間おきなら成功・8時間あくと失敗しやすい」を保つ。
- 内装ガチャの景品は「解放」で、出た物は何個でも置ける（置くときはコイン）。重複はコインに替える。
- 環境保護区（Lv6）は維持費がエコツアー収入より必ず大きい。見返りは来館者の倍率。
- 詳細と数値は `docs/monetization.md`。

### 共有
- 水槽の写しを Supabase `shared_tanks` へ、画像を公開ストレージへ。閲覧は `share.html?id=`（ログイン不要）。
- 共有 URL は Worker が水槽ごとの og:image を返し、人は閲覧ページへ送る。制限は1人3件・64KB・1分に1回・90日未閲覧で自動削除。

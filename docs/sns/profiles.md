# SNS アカウントの設定（貼り付け用）

画像は `docs/sns/headers/`。アイコンは全SNS共通で `profile_icon_1024.png`（夜の紺の円形水槽）。
リンクの `utm_source` は、どのSNSから来たかを数えるための印（SNSごとに変えてある）。

## 共通
- 表示名：`アクスタ｜水族館づくりゲーム`
- 使うSNSは Instagram と Threads の2つだけ（X・TikTok・YouTube は使わない）
- ハッシュタグ：`#アクスタ` `#マイ水槽`（投稿の募集用） `#水族館` `#アクアリウム` `#個人開発` `#indiegame`

## Threads
- Instagram のアカウントでログインすると、名前・アイコン・ユーザー名がそのまま使われる。
- 自己紹介：Instagram と同じ文。
- リンク：`https://yoshi-ochi.github.io/AquariumStudio/?utm_source=threads&utm_medium=social&utm_campaign=profile`

## どのSNSに何を出すか
| SNS | 出すもの | 頻度 |
|---|---|---|
| Instagram | リール（癒しの水槽・新種）、ストーリーズ（アンケート・実況） | リール 毎日1本、ストーリーズ 毎日 |
| Threads | 開発日記・館長のつぶやき・お知らせ・#マイ水槽 の紹介 | 1日1〜3回 |

## iPhone版が出たら変える所
- 各SNSのリンクに App Store の URL を追加（Instagram・Threads とも2つ目のリンク）。
- 自己紹介の「Web版で今すぐ遊べる」→「Web版・iPhone版はリンクから」。

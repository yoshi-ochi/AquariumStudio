# 和名だけの種の情報を補う（モデルを作る前に）

管理者ツールの「モデル待ち」タブでは、リストに無い種を和名だけで仮登録できる。
ID・学名・体形・採取地などは、モデルを作るセッションが和名から調べ、`npm run species:add` で確かめて追加予定種（モデル待ち）に加える。

## 流れ
1. 管理者ツール：和名を入れて「＋ 追加」→ 参考画像とメモを登録 →「モデル制作へ」。
2. `npm run species:pull`：画像を `reference/fish/<和名>/` に取り込む。和名だけの種は「情報が未補完」と表示され、`reference/fish/_custom.json` に残る。
3. モデルを作るセッション：下の手順で情報を補い、そのあといつもどおりモデルを作る。

## 情報を補う手順
1. `npm run species:add -- --pending` で未補完の種を見る。`memo.txt` を読む。
2. 和名から種を特定する（標準和名と学名）。**次のときは補わずに止め、理由を報告する。**
   - 総称（属・科のまとまり、「〜の仲間」「〜類」）。総称のモデルは作らない。
   - 地方名・流通名などで、どの種か決まらない（候補を挙げてユーザーに聞く）。
   - すでにいる種の別名（学名が同じ）。
   - 分布に合う採取地が1つも無い（採取地の追加はユーザーが決める）。
3. `npm run species:add -- --ranges` で、相場と選べる値（体形・模様・漁法・採取地・行動）を見る。同じ仲間の既存の行を Grep して書き方をそろえる。
4. 値を決めて JSON に書く（置き場はスクラッチ。リポジトリには入れない。形は `tools/species-add.mjs` の冒頭）。

| 項目 | 決め方 |
|---|---|
| `id` | 和名のローマ字を短く（英小文字と数字で3〜20字。例 `kobudai`）。既存と重複させない |
| `sci` | 学名（属名 種小名）。最新の分類に合わせる |
| `form` | 体形。同じ仲間の既存種に合わせる（作り方の Skill もこれで決まる） |
| `len` | 全長（m）。よく見る成体の大きさ（最大記録ではない） |
| `rarity`・`appeal` | レア度1〜4と集客力。同じ仲間で大きさの近い既存種に合わせる。相場は `--ranges` が出す（集客力の中央は、緑 2・青 4・紫 10・金 50） |
| `colors` | 体・腹・ひれの色。参考画像と図鑑から。模様は `extra` の `pat`・`mark`（帯の数は `bands`） |
| `methods` | その種を実際に獲る漁法（1〜3個） |
| `at` | 実際に分布する採取地だけ |
| `seasons` | 来遊・漁期が季節に限られる種だけ（0春〜3冬）。通年なら書かない |
| `note` | 図鑑の解説を1〜2文（60字ほど）。形の特徴と暮らし方 |
| `behavior` | 体形の既定（`src/expedition/behaviorData.js` の `FORM_BEH`）で足りないときだけ |

5. `npm run species:add -- <種.json> --dry` で確かめる。「誤り」は直し、「注意」（相場から外れているなど）は理由があるときだけ残す。
6. `--dry` を外して追記する。書き込む先は `speciesPlannedJapan.js`・`speciesPlannedReef.js`・`speciesPlannedWorld.js` のどれか（採取地から決まる）の末尾。
7. **スクリプトが出した一覧（○×つき）を、そのまま報告に載せる。** ユーザーが直せるようにするため。
   - ○：公開後に管理者ツールの「魚種」タブで直せる（全長・レア度・集客力・季節・漁法・採取地・解説・行動）。
   - ×：データのファイルを直す（id・学名・体形・色・模様）。id は公開後に変えない（プレイヤーの在庫が id で残る）。

## 仕組み
- 追記しただけでは本番に出ない。モデル（`ANATOMY[id]` または `model: true`）が出来たときに出る（`src/expedition/speciesRelease.js`）。
- 管理者ツールの行（`species_intake`）は仮の id（`c_…`）のまま残り、追加予定種とは**和名**でつながる。補ったあとに和名を変えるときは、管理者ツールの行も同じ名前にする。
- `reference/fish/_custom.json` は「リスト外の種＝情報が未補完の種」の一覧。追記すると、その種はここから外れる。
- 和名の整え方と総称の見分け方は `src/admin/intakeNames.js`（管理者ツールとスクリプトが共有）。

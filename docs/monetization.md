# 通貨と課金の設計（コイン・ダイヤ）

iPhone 版リリースに向けた課金要素の全体設計。段階1（土台）は実装済み、段階2以降は未実装。

## 段階1で実装したもの（コード）
- コイン表記：`src/ui/currency.js`（`coin` / `coinText` / `dia`）
- ダイヤ：`src/management/wallet.js`（無償＝セーブ、有償＝サーバー `supabase/wallet.sql`）・`walletData.js`（入手量・アイテム・商品）
- アイテム：`src/management/items.js`、加速と採取倍の選択 `src/ui/boostPicker.js`
- 建築の工事：`src/management/construction.js`・`buildTimes.js`・注文窓口 `src/building/builder.js`
- 毎日のダイヤ：`src/game/daily.js`（ログイン・依頼・清掃25回・1日の評価）
- ショップ：`src/ui/storeView.js`（HUD のダイヤから開く）、購入窓口 `src/online/purchases.js`（開発中はテスト購入だけ）
## 段階2で実装したもの（卵ガチャ）
- 抽選・天井・ふ化：`src/gacha/gacha.js`、確率・入れ替わり：`src/gacha/gachaData.js`、画面：`src/ui/gachaView.js`（右の「ガチャ」ボタン）
- 限定種36種（4区分×9種）：`src/gacha/gachaSpecies.js`。PLANNED に入るので管理者ツールの「モデル待ち」から画像を登録できる。モデルが3種そろった区分から並ぶ
- 確率：緑60%・青28%・紫10%・金2%（出る種のないレア度は割り直す）。10連は紫以上1つ確定、金が出ずに100回で金確定（区分ごとに数える）
- ふ化：緑10分・青1時間・紫6時間・金24時間。加速アイテムが使える
- 有償ダイヤを使う回の抽選はサーバー（`supabase/gacha.sql` の gacha_draw）。無償だけの回は端末
- ガチャ限定種は図鑑の発見数・目標の発見数・採取地の達成報酬に数えない（コンプガチャ規制）

## 段階3で実装したもの（繁殖の作り直し）
- 処理：`src/breeding/breeding.js`、データ：`src/breeding/breedData.js`、画面とロードマップ：`src/breeding/breedView.js`（バックヤードの「繁殖」・図鑑の種の詳細）
- 雌雄：在庫の個体ごとに種の雌雄比で決まる（在庫数が同じなら毎回同じ）。オスとメスがそろわないと繁殖できない。性転換する種（クマノミ・ハタ・ベラ・ハナダイなど）は2匹いればよい
- しかた：卵生（産卵→ふ化→保育）・胎生/卵胎生（妊娠→出産→保育。サメ・エイ・イルカ・カサゴ・タツノオトシゴ）・抱卵（エビ・カニ）・ポリプ（クラゲ）
- 時間：産卵 緑2〜金48時間（研究で短縮）・ふ化 4〜12時間・保育 12/24/36/48時間
- 世話：産卵は半ばに1回、ふ化は3時間以上の間隔、保育は6時間ごと。次の世話が出るまでが期限。メールで知らせる
- 逃すと：産卵は60%で産卵せず。ふ化・保育は1匹ずつ死ぬ確率（ふ化40%・保育35%）。0匹なら全滅
- 保育成功：ふ化と保育の世話を80%以上期限内に済ませ、生き残りがいるとき。届かなければ生き残りの半分だけ育つ
- 目安：3時間おきに見れば成功、8時間あくと失敗しやすい（シミュレーションで確認）
- アルビノ・変色個体：0.5%（繁殖技術の研究で最大1.5%）。在庫と水槽で数を別に持ち（`expeditions.variants`・`tank.userData.variants`）、水槽ではアルビノは白っぽい桃色の体と赤い目、変色個体（黄変）は金色で泳ぐ（`src/breeding/morphColor.js`）。水槽の画面から1匹ずつ出し入れでき、成長の材料には使わない
- 深海の種（駿河湾の深海・合同調査の種など）は、繁殖水槽を2,000ダイヤで深海繁殖装置に改造すると繁殖できる
- 保育管理アイテム（6/12/24時間）：その間の世話を自動で済ませる。加速は産卵・ふ化の段階だけ

## 段階5で実装したもの（内装ガチャ・大型流木）
- 内装ガチャ（卵ガチャの画面の下・常設）：`src/decor/`。1回100・10連900ダイヤ、確率と天井は卵ガチャと同じ
- 景品21種：水槽台のデザイン6（ホワイト・ブラック・オーク・大理石・アイアン・黒漆と格子）、説明プレートのデザイン5（木札・アクリル・石碑・和紙・真鍮）、天井照明3（球形・提灯・広告のダウンライト）、館内オブジェ7（モンステラ・ケンチャヤシ・ウンベラータ・畳・障子・竹垣・石灯籠）
- 出た物は解放で、何個でも使える（置くときはコイン）。持っている物が出たらコイン（緑5,000〜金150,000）
- デザインの切り替え：水槽台・説明プレートは選んだときの詳細パネル、天井照明は部屋の照明の「器具」
- 説明プレート（新しい館内オブジェ、8,000コイン）を追加
- 大型流木5形（枝分かれ・根張り・アーチ・倒木・ねじれ）：水槽内カタログで1形300ダイヤで解放。課金の「大型流木セット」¥480で全部

## 全体仕様

### A-1 通貨
- **コイン🪙**：今の「お金（¥）」の名前と表示を変える。値はそのまま。
  - HTMLで表示する所は、CSSで描いたコインのアイコン＋数値（共通の `coin(n)`）。
  - トーストやメール本文などの文字だけの所は「1,234コイン」。
  - 共通の `src/ui/currency.js` を作り、21か所ある各ファイルの `const yen` と、約30か所の「¥」をこれに置き換える。
- **ダイヤ💎**：**有償ダイヤ**（課金で入手。サーバーで管理）と**無償ダイヤ**（遊んで入手。セーブに保存）を分けて記録する（資金決済法のため。表示は合計）。使うときは無償ダイヤから先に減らす。
- **両替**：100💎 → 50,000コイン で固定。コインをダイヤにはできない。

### A-3 アイテム（ダイヤで買う。所持数は無期限）
- **採取倍（×2）150💎／採取倍々（×4）400💎**：遠征の成果を見たあとで、受け取る前に使う。合同調査には使えない。
  - 今の `rollCatch(trip)` は trip.seed から結果が決まるので、受け取る前に結果を見せられる。
- **加速**：1分 10💎／5分 40💎／1時間 300💎／3時間 800💎。使える対象は建築・遠征（合同調査を除く）・繁殖（産卵・ふ化）・卵のふ化。保育には使えない（保育は保育管理アイテムで助ける）。
- **イベントカード**：今コインで開いているイベント4種を、カードで開く方式に変える。カードはダイヤで買う（餌やりショー 30💎／親子ふれあい 60💎／夜の水族館 120💎／特別展 400💎）。月替わり特集のミッションでももらえる。

### A-6 卵ガチャ（第2段階）
- 区分は**魚類（古代魚を含む）・両生類・爬虫類・鳥類**の4つ。同時に並ぶのは2台。
- **3日ごとに2台のうち片方が入れ替わる**（2台を交互に入れ替えるので、各台は6日間並ぶ）。順番は日付から決まる固定の並び。
- 1回100💎、10連900💎（★3以上が1つ確定）。確率は画面に表示し、100回で★4確定の天井をつける。
- 出るのは卵。ふ化に時間がかかり、加速アイテムを使える。
- **ガチャでしか手に入らない種**は `gacha` 区分を持ち、採取地の全種発見と図鑑の達成報酬からは外す（コンプガチャ規制を避けるため）。
- 抽選は有償ダイヤを使うのでサーバーで行う（Supabase RPC）。
- モデルの方針（画像が届いた種だけ作る）に従う。種の一覧をデータで先に入れ、モデル待ちにする。モデルが3種以上そろった区分からガチャに並ぶ。
  - 古代魚はシーラカンスの体形（coelacanth）を応用できる。両生類・爬虫類・鳥類は体の組み立てを新しく作り、陸のある「テラリウム水槽」も新しく作る（第8段階）。

### A-7 繁殖の作り直し（第3段階）
- **オスとメス**：在庫をオス・メス別に数える。捕れたときに、その種の実際の雌雄比で性別を決める。今の在庫は雌雄比で分けて移す。オス・メスがそろわないと繁殖できない。性転換する種（クマノミ・ベラ・ハタなど）も扱う。
- **段階**：「産卵（胎生なら妊娠）→ふ化（出産）→保育」。
- **保育にかかる時間**はレア度で決める。★1 12時間／★2 24時間／★3 36時間／★4（超レア）48時間。
- **保育はこまめな世話が必要**
  - 保育中は数時間ごとに世話の時間が来て、期限つきの世話（エサ・水換え・水温）が要る。
  - 期限を逃すたびに生き残る数が減り、**0になると全部死ぬ**。
  - **保育成功**＝ほぼ全部の世話を期限内にした場合だけ（目安は8割以上）。届かなければ失敗（生き残りがいれば少数だけ育つ）。
  - 産卵・ふ化の段階でも、水温や親の状態が悪いと失敗することがある。
- **ロードマップ**：種ごとの達成状況を、種の詳細画面とバックヤードの繁殖から見られるようにする。
- **アルビノ・変色個体**：生まれる確率は0.5%から始まり、繁殖技術の研究で最大1.5%まで上がる。図鑑では別に記録する。
- **深海繁殖装置**：繁殖水槽を2,000💎で改造する。深海の種に必要。
- **保育管理アイテム**：6時間 150💎／12時間 280💎／24時間 500💎。その間の世話は期限内にしたものとして数える。

### A-8 その他（第4〜第6段階）
- **水面の高さ（第4段階・独立）**
  - 水槽ごとに0〜100%を5%刻み（20段階）で変えられる。底にひたひたの水だけ、もできる。
  - `tankBuilder.js` / `polyTank.js` の `h*0.9` を値で渡せるようにし、interior.waterTop・クリップ・泳ぐ範囲に反映する。
  - 水深が体高より浅いと、魚は泳ぐ範囲を水面より下に限り、幸福度を下げて警告する。0%では水の生き物を入れられない。
- **大型流木（第5段階）**：枝分かれ・根張り・アーチ・倒木・ねじれの5形状。ダイヤまたは課金パックで買う。
- **内装ガチャ（第5段階）**：水槽台・説明プレートのデザイン違い（見た目の差し替え）、広告の天井にある丸いダウンライト、大型観葉植物、畳・障子・灯籠などの和風館内オブジェ。
- **環境保護区（第6段階・Lv6）**：生け簀と同じように別の画面で、海域・陸域の区画を解放する。区画の費用は億コイン単位。毎時の維持費は水族館より大きい。
  - 主な生き物は大型種・動物・クジラ類。エコツアーで一部を回収し、保護の貢献度が水族館の集客を上げる。

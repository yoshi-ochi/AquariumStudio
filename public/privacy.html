プライバシーポリシー

制定日：2026年11月18日

Aquarium Studio（アクスタ。以下「本アプリ」）における利用者情報の取り扱いを説明します。

1. 取得する情報

  • メールアドレス
  • 表示名（アカウント名）
  • パスワード（メールアドレスで登録した場合。認証基盤でハッシュ化して保管され、運営者は内容を確認できません）
  • Google アカウントでログインした場合に Google から提供される、メールアドレス、名前、プロフィール画像の URL、アカウント識別子
  • 水族館のレイアウトなどのセーブデータ
  • フレンドコード、フレンドの申請・承認の状況
  • 水族館の立地として利用者が地図で指定した位置（0.1度単位のおおまかな位置）
  • 同盟への加入状況、合同調査への出資額

2. 利用目的

  • ログインと本人確認
  • セーブデータの保存と、端末をまたいだ読み込み
  • フレンド機能と、フレンドの水族館の訪問機能の提供
  • 確認メールやパスワード再設定メールの送信

広告配信や、Google から取得した情報の販売には利用しません。

3. 他の利用者に公開される情報

表示名、フレンドコード、指定した立地は、ログイン中の他の利用者が参照できる場合があります。自宅など特定の場所を立地に指定しないでください。セーブデータは、フレンドとして承認した相手と、同じ同盟のメンバーのみが閲覧できます。メールアドレスは他の利用者に公開されません。

4. 外部サービスの利用

本アプリは次のサービスを利用しており、情報は各サービスの管理下で処理されます。法令に基づく場合を除き、これ以外の第三者に利用者情報を提供しません。

  • Supabase（認証、データベース）
  • Google（Google アカウントでのログイン）
  • GitHub Pages（本アプリの配信）

5. 端末への保存

ログイン状態を保つため、認証情報を利用者の端末のブラウザ内に保存します。ログアウトすると、その端末から削除されます。

6. 情報の保管と削除

利用者情報は、アカウントが存在する間保管します。アカウントと関連データの削除を希望する場合は、下記のお問い合わせ先からご連絡ください。

7. お問い合わせ

GitHub Issues からご連絡ください。Issues は公開されるため、メールアドレスなどの個人情報は書き込まないでください。

8. 本ポリシーの変更

内容を変更する場合は、このページで告知します。

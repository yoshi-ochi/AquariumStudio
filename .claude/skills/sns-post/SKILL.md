# SNS の手順

最初に `docs/areas/sns.md` だけ読む。設定の文面は `docs/sns/profiles.md`、リールの台本の手本は `docs/sns/reel-01.md`（必要なときだけ読む）。

## 0. 前提
- 使うのは Instagram と Threads だけ。
- **投稿・返信・アカウントの設定変更は Claude が行わない。** 文面・台本・素材を用意し、投稿はユーザーが行う。
- 書いてよいのは、本番で実際に遊べる内容だけ。未公開の生き物や機能は「予定」と書く。数字（種の数など）は `docs/areas/model.md` かコードで確かめる。

## 1. リールを作る
1. 台本を `docs/sns/reel-NN.md` に書く（`reel-01.md` と同じ形：形・出る生き物・音・構成の表・投稿文・Threads の文・表紙）。
   - 縦 9:16（1080×1920）。最初の2秒で何の動画かわかる絵にする。最後が最初につながると繰り返し見られる。
   - 文字は短く中央寄り（上220px・下420px は置かない）。声は入れない。
2. 撮影の道具は `tools/reel/reelNN.js`（`tools/reel/reel01.js` を手本に、置く物・魚・カメラの動きを表で持つ）。
3. `preview_start {name: "dev"}` で開き、コンソールから道具を読み込んでコマを撮る → ffmpeg で MP4 にまとめる。
4. 動画・音は git に入れない（`docs/sns/reel-NN/` に置く。`.gitignore` 済み）。台本と道具だけコミットする。
5. 出来た動画をユーザーに見せ、確認をもらう。

## 2. 投稿文を書く
- Instagram：1行目で内容を言い切る → 2〜4行の説明 → 「Web版は無料で遊べます（プロフィールのリンクから）」→ コメントを誘う問いかけ1つ → ハッシュタグ（`#アクスタ` を先頭に、生き物の名前を足す。10個前後）。
- Threads：2〜3行の話し言葉。開発日記・館長のつぶやき・お知らせ・`#マイ水槽` の紹介。リンクは `utm_source=threads` のもの。
- 新種の紹介は、公開日（`src/expedition/speciesReleases.js`）と図鑑の解説（`note`）を元にする。作り話の生態を書かない。
- 絵文字は1投稿に1〜2個まで。誇張（「神ゲー」など）や他社作品の名前は使わない。

## 3. 計画
- Instagram はリール毎日1本・ストーリーズ毎日、Threads は1日1〜3回。1週間分をまとめて表にする（日付・種類・題材・素材の有無）。
- 題材の元：新しく公開した種、ユーザーの水槽（共有機能）、開発の裏話、季節の生き物。

## 4. 仕上げ
- `npm run docs:check` → `docs/areas/sns.md` の「いまの状態」「次にやること」を書き換える（作った台本・投稿済みかどうか）。
- 台本と道具をコミット → push → PR。マージはユーザーの確認後。

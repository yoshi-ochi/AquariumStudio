# ウミウシのモデル作成

最初に `docs/areas/model.md` を読む（共通の決まり・保留・ユーザーの指示）。魚のトレース（Python）は使わない。

## 1. 作り始めてよい条件
- 参考画像が届いた種だけ（`reference/fish/<和名>/main.*`、補助 `ref-*`、指示 `memo.txt`）。`memo.txt` は必ず読む。
- ワークツリーで作業しているときは、本体のフォルダ（`D:\claude_app\AquariumApp\reference\fish\`）の画像を読む。
- 総称の種は作らない。他社作品の絵に見える画像はユーザーに確認する。

## 2. 形態の調査（毎回）
- 図鑑・学術情報で、体形（葉状突起を背負う／外鰓がある／ミノが並ぶ）、触角の形と色、突起やミノの数・並び・先端の色、体の模様、全長を調べる。
- 調べたことと反映したことを報告に書く。

## 3. 作り方
- 置き場所は `src/expedition/creatureSlug.js`。全長1に正規化、+X が頭、y=0 が底。300行を超えそうなら体形ごとに `creatureSlugXxx.js` に分ける。
- 部品（同じファイルの関数を使い回す）：
  - `band`：輪と輪を帯でつなぐ（体の胴）。`tris`：面ごとに色を塗る。
  - `leaf`：背の突起。**ふっくらした紡錘形が既定**（`plump`）。平たい葉にしない。
  - `patch`：ほほの斑などの模様。**浮かせず体の面に貼る**。
  - `spike`（触角など細い物）、`gem`（目などの粒）。
- **面の数を抑える**：球や円柱を使わない。1種でおよそ500枚（突起1本は三角形16枚）を目安にする。
- 色は `c.colors`（body・belly・fin）と `c.mark` から決める。下向きの面は陰で濃く見えるので、淡めにしておく。
- 新しい体形を足すとき：
  1. 体形の関数を書き、`src/expedition/creatureSoft.js` の `BUILDERS` に体形名で登録する。
  2. 底を這う種は `BENTHIC_FORMS` に、行動は `src/expedition/behaviorData.js`（体形ごとの既定と `GROUND`）に足す。
  3. 種のデータ（`src/expedition/speciesPlannedReef.js` など）で `form` をその体形名にし、`model: true` を付ける。
- 同じ体形の別種は、関数を写さず `c` の値（色・突起の数・大きさ）で作り分ける。

## 4. 確認（右のプレビュー）
1. `preview_start {name: "model-viewer"}` → `/?id=<id>` を開く。ドラッグで全角度、ホイールで拡大。
2. 横・正面・上・斜めを見て、参考画像と並べて比べる。三角形の数は画面の情報欄に出る。
3. スクリーンショットをユーザーに見せ、**確認をもらってから**本番へ。

## 5. 本番へ
1. `npm run build`。
2. `npm run species:release`（公開日の記録）。
3. `npm run docs:check` → `docs/areas/model.md` の「いまの状態」を書き換える（新しく受けた作り方の指示も足す）。
4. ブランチ `fish/<id>` → コミット（`feat(fish): ○○を追加`）→ push → PR。マージはユーザーの確認後。

## 報告の形
- 作った種：和名（id）／参考画像の種類／三角形の数
- 調べた特徴と反映（1行ずつ）
- 未確認のこと（水槽の中での見え方など）

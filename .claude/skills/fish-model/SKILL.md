# 魚モデル生成スキル

最初に `docs/areas/model.md` を読む（保留・差し替え待ち・最新の弾・ユーザーから受けた作り方の指示）。

## 0. 返答のルール（日本語）
- 返答・コメント・報告・コミットメッセージの説明部分はすべて日本語。前置き・挨拶・謝罪は書かない。
- 報告は短く、次の形で出す：
  - **作った種**：和名（id）／参考画像の種類（写真・イラスト・上面図）
  - **調べた特徴と反映**：体形・側線・縞／斑点／帯・ひれの形や条・雌雄差など → どう反映したか（1行ずつ）
  - **確認待ち**：比較画像のパス（例 `reference/fish/compare_batchNN.png`）
  - **保留・差し替え依頼**：理由を1行
- ファイル全体は出さず、変更点だけ示す。

## 1. 作り始めてよい条件
- 参考画像が届いた種だけ作る。届いていない種は作らない（データだけ先に入れて「モデル待ち」にする）。
- 画像の置き場：`reference/fish/<和名>/main.*`（メイン）、`ref-*`（補助）、`memo.txt`（指示）、リスト外の種（和名だけ。情報が未補完）は `_custom.json`。旧形式 `reference/fish/<和名>.(png|jpg)` もメイン扱い。
- 取り込み：管理者ツール「モデル待ち」タブ → `npm run species:pull`。手元の登録は `npm run fish-intake`。
- **memo.txt は必ず読んで反映する。**
- メイン画像はユーザーが選ぶ。Claudeが勝手に選び直さない。真上・正面など別角度は厚みの参考としてClaudeが探してよい。
- 総称（属・科レベル）の種は作らない。
- 他社ゲーム・作品の図鑑イラストに見える画像はトレースしない（ユーザーに確認し、別画像に切り替える）。イラスト・図版自体は可。
- 次の画像は差し替えを依頼する：斜め・青かぶり／緑かぶり・ぼやけ・複数個体の重なり・別種に見えるもの。
- 保留・差し替え待ちは `docs/areas/model.md`（保留種はユーザーが解くまで作らない）。優先は「追加予定（採取地あり）」の種（`src/expedition/speciesRoster.js` の PLANNED）。

## 1.5 和名だけの種は、まず情報を補完する
- `npm run species:pull` が「情報が未補完」と出した種（一覧は `npm run species:add -- --pending`）は、追加予定のリストに無い。モデルの前に情報を補う。
- 手順は `docs/species-add.md`：和名から種を特定 → id・学名・体形・全長・レア度・集客力・色・漁法・採取地・季節・解説（要るなら行動）を調べる → `npm run species:add -- <種.json> --dry` で確かめて追記。
- 総称・どの種か決まらない和名・すでにいる種の別名は、補わずに「作らない」と理由を報告して止める。
- 補った値は、スクリプトが出す一覧（○＝管理者ツールの「魚種」タブで後から直せる／×＝ファイルを直す）をそのまま報告に載せる。

## 2. 形態の調査（毎回）
- 図鑑・学術情報で、体形・側線・稜鱗・縞・斑点・帯・ひれの形と条・婚姻色・雌雄差・発光器などを調べる。
- 参考画像が雌型／幼魚などの場合はその型で作り、報告に明記する。
- 生成スクリプトの種ごとのコメントに特徴を1行で書く（例：`# ---- コブダイ：オスは額がこぶ状…`）。

## 3. 作り方（トレース方式）
- 生成スクリプトは `reference/fish/_gen/`（git管理外）。共通部は `lib_head.py`・`lib_writer.py` を `exec` で読み、新しい弾は `genNN.py` として作る（`gen24.py` が最新の手本）。
- 出力先は `src/expedition/creatureAnatomyPhotoNN.js` の `PHOTO_ANATOMY_NN`。`creatureAnatomy.js` に import と `...PHOTO_ANATOMY_NN` を追加する。1ファイル肥大化を避け、弾ごとに新ファイルにする。
- 体：`top`／`bot` の輪郭点をトレースし、細かい格子（`n` 列 × `rows` 行、目安 n=32〜36・rows=8〜12）で、各マスの色を写真から写す（`cellsB64`）。
  - **細かすぎは不可**（84×36マスは「リアルすぎる」と却下）。チョウチョウウオ類は 21×9 程度＋縞は `decals`（写真から測った線）。
- ひれ：`fin_on`（体の輪郭に沿う）、`fine_fin`（任意の付け根）、尾びれは `tb()` で付け根を作る。胸びれは `lift` で浮かせる。
- 厚み：`dmax`（最大厚）・`peak`（最も厚い位置）で推定。目 `eye`、口 `mouth` を指定。
- 特殊な体：
  - 上からの写真しかない種・ウミガメ → `topView`。
  - 水平な尾びれ（イルカ等）→ `plates`。
  - 発光する種 → `glow`（`pts`・`hex`・`halo`）。水槽が暗いほど強く光る。
  - 輪郭をなぞらない種（クラゲ・イカ・カブトガニ・チンアナゴ等）→ Skill `creature-model`。ウミウシ → Skill `slug-model`。
- 泳ぎ方・行動は `src/expedition/behaviorData.js` に種ごとに追加（mode 4 ウミガメ、mode 5 イルカ など）。予定種は登録済みか確認。
- 参考画像は計測にだけ使い、アプリに組み込まない。

## 4. 確認と本番反映
1. `preview_start {name: "model-viewer"}` → `/?id=<id>` を開き、右のプレビューで全角度から確かめる（ドラッグで回転。参考画像と並ぶ。厚み・ひれの付け根・上からの形を見る）。
1. 比較画像（参考画像と生成モデルを並べたもの）を `reference/fish/compare_batchNN.png` に作り、ユーザーに見せる。
2. **ユーザーの確認をもらってから**本番へ。却下された種は直すか保留にする。
3. `npm run build` で通ることを確認。
4. `npm run species:release` で公開日を記録。
5. ブランチ → コミット（`feat(fish): ○○種を追加`）→ PR → main へマージで公開（ログイン時に新種一覧が出る）。
6. 終わったら `npm run docs:check` → `docs/areas/model.md` の「いまの状態」を書き換える（最新の弾・保留・差し替え待ち・新しく受けた指示）。メモリには書かない。
